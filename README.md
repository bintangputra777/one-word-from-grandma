# One Word From Grandma

One word: the word grandma would text about AI, for make.fun's
["One Word From Grandma"](https://make.fun/bounty/u-0xkianno-one-word-from-grandma-f04bed16)
bounty ($5 across the top 8 places, judged pairwise on funniness and how
grandma-like the word is).

## The word

> DOOHICKEY

The word a grandma types when she can't remember what the new AI gadget is
called — warm, baffled, and exactly what she'd text her grandchild.

## How it works

`main.ts` writes the single word to `/output/entry.txt` (9 characters, one
word, no trailing newline).

Run it twice — the output is byte-identical every time:

```sh
node main.ts
```
